# Profile animations

The profile uses original GIFs, with source assets stored in this repository. The published copies are hosted at `https://kirito14it.github.io/github-profile/` so GitHub's image proxy can serve them without a direct connection to raw.githubusercontent.com. No animation service or scheduled workflow is required.

To regenerate, install Node.js with `sharp` and `@napi-rs/canvas`, and Python with `Pillow`, then run from the repository root:

```sh
node scripts/render-profile.cjs
python scripts/encode-profile.py
node scripts/render-contact-badges.cjs
```

The generator renders 80 frames at 1200 pixels wide. The encoder uses a shared palette, checks for visible motion and a smooth loop, and enforces a 5 MB budget per image. Intermediate PNGs in `output/` are ignored by Git.

`assets/research-greeting-neon.svg` is an editable static vector version of the banner. Update the text and visual parameters in `scripts/render-profile.cjs` before regenerating the published GIFs. The neon version uses cyan, violet, pink, amber and blue for its particle clusters, moving orbital trails and signal paths. The greeting includes embedded color emoji rendered with Windows Segoe UI Emoji; set `PROFILE_EMOJI_FONT` to another color emoji font path on other systems. The encoder reserves warm emoji colors as well as neon highlights.

The three contact buttons are full-color SVGs generated by `scripts/render-contact-badges.cjs`. The globe and envelope are original drawings. The Google Scholar icon uses [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/googlescholar.svg), under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).

After regeneration, copy `research-greeting-neon.gif`, `signal-flow-neon.gif`, `academic-homepage-neon.svg`, `google-scholar-neon.svg` and `email-neon.svg` to `public/github-profile/` in the `Kirito14IT.github.io` repository and deploy that site. Earlier banner versions are retained as originals. Publish assets before switching README URLs so GitHub's proxy never caches missing files.

The inline lab logos, `assets/fudan-university-logo.png` and `assets/fudan-teai-logo.png`, are unmodified transparent PNGs supplied by the profile owner. They retain their original colors and are displayed at 22 pixels, with both the logo and label linked to the corresponding organization. Publish identical copies in `public/github-profile/` before updating the profile README.
